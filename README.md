# Ollama Launcher
This repository contains the launcher for the Ollama platform.

## Project Structure
- `logger.py`: Logger module implementation.
- `proxy.py`: Proxy server module implementation.
- `Python_Interface.py`: Interface to communicate with the Ollama platform.

## Usage Instructions
To use this project, clone it and run:
1. Install dependencies: `pip install -r requirements.txt`
2. Start the launcher: `start_all.bat`
